# АвторLab

Школьный проект о распознавании происхождения русскоязычных стихотворений. Интерфейс работает на GitHub Pages, проверка выполняется на внешнем сервере. Посетителям не требуется скачивать веса, устанавливать программы или вводить ключи.

## Обновление сайта

1. Распакуйте архив.
2. Откройте репозиторий `tokyoshikM/authorlab` на GitHub.
3. Выберите **Add file → Upload files**.
4. Загрузите содержимое архива с заменой существующих файлов. Важно добавить новый `detector-api.js`, обновлённые `app.js` и `index.html`.
5. Сохраните изменения в ветке, из которой публикуется GitHub Pages.
6. Дождитесь публикации и обновите страницу сайта.

Загружайте содержимое архива, а не сам ZIP. Файлы должны находиться в корне репозитория рядом с `index.html`.

Если раньше была загружена версия с вычислениями в браузере, её `model-client.js`, `model-worker.js`, `model-core.js`, `assets/model` и `assets/runtime` больше не используются. Их можно удалить; оставленные старые файлы не будут загружаться новым сайтом.

При включении Pages с нуля: **Settings → Pages → Deploy from a branch → main → /(root) → Save**. Файл `.nojekyll` нужно сохранить.

## Использование

Откройте «Детектор», вставьте русскоязычное стихотворение из 2–80 строк, до 10 000 символов, и нажмите «Проверить стих». Текст отправляется на внешний сервер на Hugging Face только после нажатия кнопки. До отправки выполняется проверка формата. Литературный разбор рассчитывается на устройстве.

Для работы нужен интернет. Если сервер запускается или перегружен, сайт делает одну повторную попытку. При недоступности или некорректном ответе выводится сообщение об ошибке; искусственно рассчитанного запасного результата нет. При уходе из раздела запрос отменяется в браузере, хотя уже начавшаяся обработка на сервере может продолжиться.

Неизменённые результаты эксперимента сохраняются в браузере и экспортируются как раньше. Текст, введённый в детектор, в локальное хранилище не записывается.

## Структура

- `app.js` — интерфейс, эксперимент и отчёт.
- `core.js`, `data.js` — эксперимент и сохранение результатов.
- `classics.js` — справочная база литературных источников.
- `detector.js` — литературный разбор.
- `detector-api.js` — запрос к удалённому детектору и проверка ответа.
- `METHOD.md` — техническое описание метода и ограничений.

## Проверки

При наличии Node.js 18 или новее:

```bash
node --test tests/*.test.js
```

Тесты проверяют программную логику и обработку сетевых ответов. Они не подтверждают точность распознавания произвольных стихов.
